# ADRs — Architecture Decision Records

Decisões técnicas relevantes do projeto. Cada ADR explica o contexto, a decisão tomada, e as alternativas consideradas.

Use o template abaixo para criar uma nova ADR:

```markdown
# ADR-[N]: [título curto da decisão]

**Data:** YYYY-MM-DD  
**Status:** Aceita | Deprecada | Substituída por ADR-[N]

## Contexto

[O problema que precisava de uma decisão. O que estava acontecendo, quais eram as restrições.]

## Decisão

[O que foi decidido. Direto — sem justificativa aqui ainda.]

## Consequências

[O que muda com essa decisão. Prós, contras, e o que fica como TODO.]

## Alternativas consideradas

[O que mais foi avaliado e por que não foi escolhido.]
```
